# VTuber 案例

## 角色设定
- 职业：虚拟主播
- 风格：可爱
- 特色：双马尾

## Cubism 参数设置

### 基础参数
- ParamAngleX: -30 到 30
- ParamAngleY: -20 到 20
- ParamAngleZ: -25 到 25
- ParamEyeLOpen: 0 到 1
- ParamEyeROpen: 0 到 1
- ParamMouthOpenY: 0 到 1
- ParamMouthForm: 0 到 1
- ParamBodyX: -15 到 15
- ParamBodyY: -10 到 10

### 表情参数
- ParamSmile: 0 到 1
- ParamWinkL: 0 到 1
- ParamWinkR: 0 到 1

## 工作流
1. 导入 PSD
2. 检查 Draw Order
3. 设置 Mesh
4. 设置 Warp Deformer
5. 建立 AngleX/Y/Z
6. 建立 MouthForm
7. 物理设置
8. 导出
