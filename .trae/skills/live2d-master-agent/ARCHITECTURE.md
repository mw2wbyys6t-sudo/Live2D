## 🧩 核心模块

### 1. 接口定义 (core/interfaces.py)

定义所有核心组件的抽象接口，实现**依赖倒置原则**。

```python
class ImageGenerator(ABC):
    @abstractmethod
    def generate(self, prompt: str, **kwargs) -> str:
        """生成图片并返回路径"""
        pass
```

**接口列表：**
| 接口 | 职责 | 实现类 |
|------|------|--------|
| `ImageGenerator` | 图像生成 | `SenseNovaGenerator`, `VolcEngineGenerator` |
| `LayerSeparator` | 图像分层 | `KMeansSeparator`, `ColorSeparator` |
| `PSDExporter` | PSD导出 | `PSDToolsExporter` |
| `QualityAssessor` | 质量评估 | `Live2DQualityAssessor` |
| `WorkflowStep` | 工作流步骤 | `GenerateStep`, `LayerStep`, `ExportStep` |

### 2. 工作流引擎 (core/workflow_engine.py)

实现**工作流模式**，支持步骤编排、重试、回滚。

```python
engine = WorkflowEngine('live2d_pipeline')
engine.add_step(GenerateStep()) \
      .add_step(LayerStep()) \
      .add_step(ExportStep())
result = engine.execute({'prompt': '蓝发猫耳少女'})
```

**特性：**
- 链式调用 API
- 自动重试（指数退避）
- 错误隔离
- 执行时间统计

### 3. 安全配置 (config.py, secure_storage.py)

**安全存储策略：**

```
API密钥存储层级（从强到弱）：
1. 加密文件 (.env.encrypted) - Fernet加密
2. 私有字典 (_secrets) - 内存存储
3. 环境变量 (os.environ) - 兼容旧代码
```

## 🚀 扩展指南

### 添加新的图像生成器

```python
from core.interfaces import ImageGenerator

class MyGenerator(ImageGenerator):
    def generate(self, prompt: str, **kwargs) -> str:
        # 实现生成逻辑
        return "path/to/image.png"
    
    def is_available(self) -> bool:
        # 检查是否可用
        return True
    
    def get_name(self) -> str:
        return "MyGenerator"
```

### 添加新的工作流步骤

```python
from core.interfaces import WorkflowStep

class MyStep(WorkflowStep):
    def execute(self, context: Dict) -> Dict:
        # 实现步骤逻辑
        context['my_result'] = 'done'
        return context
    
    def get_name(self) -> str:
        return "MyStep"
    
    def can_retry(self) -> bool:
        return True
```

## 📊 性能考虑

### 优化策略

| 层面 | 策略 | 实现 |
|------|------|------|
| 网络 | 连接池 | requests.Session |
| 计算 | 并发处理 | goroutine |
| 缓存 | 请求缓存 | LRU Cache |
| 存储 | 异步IO | 非阻塞文件操作 |

### 资源限制

| 资源 | 限制 | 说明 |
|------|------|------|
| API请求 | 60/分钟 | 速率限制 |
| 脚本执行 | 5分钟 | 超时控制 |
| 请求体 | 32MB | 大小限制 |
| 内存 | 系统限制 | 进程隔离 |

## 🧪 测试策略

### 测试金字塔

```
        /\
       /  \
      / E2E \      端到端测试 (少量)
     /────────\
    /  Integration\  集成测试 (中等)
   /────────────────\
  /    Unit Tests    \ 单元测试 (大量)
 /────────────────────\
```

### 关键测试点

- **接口契约测试**: 验证接口实现符合契约
- **工作流测试**: 验证步骤编排正确
- **安全测试**: 验证输入验证、加密功能
- **性能测试**: 验证并发、缓存效果

---

**架构设计原则：**
1. **单一职责**: 每个模块只做一件事
2. **开闭原则**: 对扩展开放，对修改关闭
3. **依赖倒置**: 依赖抽象接口
4. **安全默认**: 默认启用安全防护
