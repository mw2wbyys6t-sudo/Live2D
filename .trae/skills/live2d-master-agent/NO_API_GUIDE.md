# Live2D Master Agent - 无 API 使用指南

## 📋 概述

即使没有配置 Seedream API 密钥，Live2D Master Agent 仍然可以完成 **80%** 的 Live2D 制作工作！

---

## ✅ 完全离线可用的功能

### 1. PSD 质量检查 (QA)

**功能说明**:
- 检查 PSD 文件是否符合 Live2D 规范
- 检测图层命名是否规范
- 分析遮挡关系
- 检测透明度和混合模式
- 生成详细的质量报告

**使用方法**:
```
检查这个 PSD 文件
```

**输出内容**:
- 综合评分（0-100）
- 问题清单（严重/警告/建议）
- 修复建议
- 统计信息

---

### 2. PSD 分层规划

**功能说明**:
- 根据角色特征规划图层结构
- 提供 Draw Order 建议
- 生成命名规范
- 标注可动部件

**使用方法**:
```
帮我规划 PSD 分层
这是一个粉色长发的动漫少女
```

**输出内容**:
- 完整的图层列表
- Draw Order 排序
- 命名建议
- 分组建议

---

### 3. Cubism 参数设计

**功能说明**:
- 设计参数配置
- 推荐参数范围
- 提供参数命名建议

**使用方法**:
```
设计 Cubism 参数
```

**输出内容**:
- 标准参数列表
- 参数范围设置
- 参数组合建议

---

### 4. 物理设置

**功能说明**:
- 计算物理参数
- 提供头发、配饰的物理建议
- 生成物理配置 JSON

**使用方法**:
```
设置物理参数
角色有长发和蝴蝶结
```

**输出内容**:
- 重力参数
- 阻尼系数
- 弹簧常数
- 物理配置 JSON

---

### 5. Rigging 指导

**功能说明**:
- 提供详细的绑定操作指南
- 步骤说明
- 最佳实践

**使用方法**:
```
提供 Rigging 指导
```

**输出内容**:
- 分步操作指南
- 注意事项
- 常见问题解决

---

## 🎨 图像获取替代方案

### 方案 1: 使用已有图片 ⭐ 推荐

**步骤**:
1. 准备你的角色立绘图片（PNG/JPEG）
2. 上传到 Live2D Master Agent
3. 进行后续处理

**优点**:
- ✅ 完全免费
- ✅ 可控性强
- ✅ 质量有保障

### 方案 3: 手绘/约稿

**手绘流程**:
1. 绘制角色立绘
2. 扫描或拍照
3. 导入 Photoshop
4. 分层处理
5. 导入 Live2D Master Agent 检查

**约稿流程**:
1. 委托画师绘制
2. 要求提供分层 PSD
3. 导入检查和优化
