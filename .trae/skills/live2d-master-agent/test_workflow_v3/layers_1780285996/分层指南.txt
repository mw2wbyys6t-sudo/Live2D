💡 导入Live2D Cubism Editor步骤
--------------------------------------------------------------------------------
1. 打开 Live2D Cubism Editor
2. 选择 File > Import PSD
3. 选择生成的 layers.psd 文件
4. 导入设置：
   - 勾选 Create ArtMeshes
   - 建议选择 Standard 模式
5. 在画布上确认图层导入
6. 在时间线面板按照建议顺序排列图层
