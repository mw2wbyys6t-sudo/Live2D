================================================================================
📦 Live2D 分层包 - 使用说明
================================================================================

📂 文件说明:
   - 00_原图.png: 原始优化图
   - 01_XX.png ~ NN_XX.png: 分层文件（PNG格式）
   - 分层指南.txt: 详细的分层顺序和导入指南

🎨 导入方法（如果没有PSD文件）:
1. 在Live2D Cubism Editor中新建项目
2. 选择 File > Import Images
3. 选择所有PNG分层文件（除了原图）
4. 在时间线面板按照分层指南排列顺序
5. 为每个图层创建 ArtMesh

💡 提示:
   - 如需生成完整PSD文件，请安装: pip install psd-tools
   - 然后重新运行本工具
