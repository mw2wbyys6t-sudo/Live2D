================================================================================
📦 Live2D 官方标准分层包
================================================================================

📂 文件说明:
   - 00_原图.png: 原始优化图
   - 01_XX.png ~ NN_XX.png: 分层文件（PNG格式）
   - 预览图: 整体效果预览
   - 分层指南: 官方标准导入步骤

🎨 导入方法:
1. 在Live2D Cubism Editor中新建项目
2. 选择 File > Import Images 或直接拖入PSD
3. 选择所有PNG分层文件（除了原图）
4. 在时间线面板按照分层指南排列顺序
5. 为每个图层创建 ArtMesh

📋 官方标准要求:
   - 画布高度: 3000-8000px
   - 头部大小: ≥1000px
   - 分辨率: 300dpi
   - 颜色模式: RGB
   - 颜色通道: 8bit/channel
   - 颜色配置文件: sRGB

⚠️ 注意事项:
   - 所有图层必须命名
   - 不能有同名图层
   - 遮挡部分必须补全
   - 连接处需要渐变
   - 仅使用正常和正片叠底混合模式
