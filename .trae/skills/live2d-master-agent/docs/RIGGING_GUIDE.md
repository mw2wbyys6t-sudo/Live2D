## 基础概念

### 什么是 Rigging？

Rigging（绑定）是将静态的 PSD 图层转换为可动 Live2D 模型的过程。通过设置参数、创建变形器和添加物理效果，使角色能够自然地动起来。

### 核心概念

| 概念 | 说明 |
|------|------|
| **参数** | 控制模型动作的数值（如 ParamAngleX 控制头部左右转动） |
| **变形器** | 存储形状变化数据的容器 |
| **网格** | 用于控制变形的网格覆盖 |
| **物理** | 模拟物理效果（如头发飘动） |
| **Draw Order** | 图层绘制顺序 |

## 详细绑定步骤

### 步骤 1: 导入 PSD 文件

1. 打开 Live2D Cubism Editor
2. 选择 `文件 > 导入 PSD`
3. 选择准备好的 PSD 文件
4. 检查图层是否正确导入

**注意事项**:
- 确保 PSD 使用 RGB 模式
- 确保所有图层使用 Normal 混合模式
- 检查图层命名是否规范

---

### 步骤 2: 设置画布

1. 设置画布尺寸（推荐 2048x2048）
2. 设置模型中心点
3. 调整图层位置

**推荐设置**:
```
画布大小: 2048x2048
模型中心: (1024, 1024)
FPS: 60
```

---

### 步骤 3: 创建参数

#### 3.1 头部参数

| 参数 | 范围 | 说明 |
|------|------|------|
| ParamAngleX | [-30, 30] | 左右转动 |
| ParamAngleY | [-30, 30] | 上下点头 |
| ParamAngleZ | [-30, 30] | 歪头 |

#### 3.2 眼睛参数

| 参数 | 范围 | 说明 |
|------|------|------|
| ParamEyeLOpen | [0, 1] | 左眼睁开 |
| ParamEyeROpen | [0, 1] | 右眼睁开 |
| ParamEyeBallX | [-1, 1] | 眼球左右 |
| ParamEyeBallY | [-1, 1] | 眼球上下 |

#### 3.3 嘴巴参数

| 参数 | 范围 | 说明 |
|------|------|------|
| ParamMouthOpenY | [0, 1] | 张嘴程度 |
| ParamMouthForm | [-1, 1] | 嘴型（撇嘴到微笑） |

---

### 步骤 4: 创建变形器

#### 4.1 头部变形器

```
结构:
└── Head (旋转变形器)
    ├── Face
    │   ├── Eyes
    │   │   ├── EyeL
    │   │   └── EyeR
    │   ├── Eyebrows
    │   └── Mouth
    └── Hair
        ├── HairFront
        └── HairBack
```

#### 4.2 身体变形器

```
结构:
└── Body (旋转变形器)
    ├── Torso
    ├── Arms
    │   ├── ArmL
    │   └── ArmR
    └── Skirt
```

---

### 步骤 5: 设置网格

1. 选择需要变形的图层
2. 创建网格（`Ctrl+G`）
3. 调整网格密度（推荐 4x4 到 8x8）
4. 设置网格权重

**网格密度建议**:
- 简单部件（眼睛）: 2x2
- 中等部件（脸部）: 4x4
- 复杂部件（头发）: 8x8 或更高

---

### 步骤 6: 创建关键形状

#### 6.1 头部转动

1. 选择头部变形器
2. 设置 ParamAngleX 的关键点:
   - -30: 头部向左转
   - 0: 正面
   - 30: 头部向右转

#### 6.2 眼睛动作

**眨眼**:
1. 设置 ParamEyeLOpen/ROpen
2. 创建关键点:
   - 0: 闭眼
   - 1: 睁眼

**视线移动**:
1. 设置 ParamEyeBallX/Y
2. 创建眼球移动的关键形状

#### 6.3 嘴型变化

| 口型 | ParamMouthOpenY | ParamMouthForm |
|------|-----------------|----------------|
| 闭嘴 | 0 | 0 |
| 微笑 | 0 | 1 |
| 张嘴 | 1 | 0 |
| 撇嘴 | 0 | -1 |

---

### 步骤 7: 设置物理效果

#### 7.1 头发物理

```json
{
  "type": "hair",
  "settings": {
    "gravity": 0.5,
    "airResistance": 0.85,
    "springConstant": 0.3,
    "damping": 0.7
  }
}
```

#### 7.2 配饰物理

```json
{
  "type": "accessory",
  "settings": {
    "gravity": 0.3,
    "airResistance": 0.9,
    "springConstant": 0.2,
    "damping": 0.8
  }
}
```

---

### 步骤 8: 添加动画

#### 8.1 呼吸动画

1. 创建 ParamBreath 参数
2. 设置循环动画:
   - 0: 正常
   - 1: 吸气

#### 8.2 眨眼动画

1. 设置自动眨眼
2. 配置眨眼间隔（推荐 3-5 秒）

---

### 步骤 9: 测试和调整

1. 使用预览窗口测试所有动作
2. 检查变形是否自然
3. 调整物理参数
4. 优化性能

---

### 步骤 10: 导出模型

1. 设置导出选项
2. 导出 model3.json
3. 测试导出的模型

---

## 部件绑定指导

### 👀 眼睛绑定

#### 步骤

1. **创建眼睛变形器**
   - 为每个眼睛创建旋转变形器
   - 设置 ParamAngleX/Y 影响

2. **设置眼球移动**
   - 创建 ParamEyeBallX/Y
   - 调整虹膜和瞳孔的位置变化

3. **创建眨眼**
   - 设置 ParamEyeLOpen/ROpen
   - 创建闭眼形状
   - 添加中间过渡形状

4. **添加高光**
   - 创建独立的高光图层
   - 设置跟随眼球移动

#### 常见问题

- **问题**: 眨眼不自然
- **解决**: 添加中间过渡形状，使用曲线编辑器调整

---

### 👄 嘴巴绑定

#### 步骤

1. **创建嘴巴变形器**
   - 使用弯曲变形器
   - 设置 ParamMouthOpenY 和 ParamMouthForm

2. **创建口型**
   - A口型: 大张嘴
   - I口型: 扁嘴
   - U口型: 圆嘴
   - E口型: 微张扁嘴
   - O口型: 圆形张嘴

3. **添加舌头和牙齿**
   - 创建舌头图层
   - 设置跟随张嘴显示

---

### 💇 头发绑定

#### 步骤

1. **创建头发变形器**
   - 为每束头发创建变形器
   - 设置 ParamAngleX/Y/Z 影响

2. **添加物理**
   - 设置头发物理参数
   - 调整重力和阻尼

3. **设置风吹效果**
   - 创建风吹参数
   - 设置飘动动画

#### 物理参数建议

| 头发类型 | 重力 | 阻尼 | 弹簧 |
|----------|------|------|------|
| 短发 | 0.6 | 0.8 | 0.4 |
| 中发 | 0.5 | 0.7 | 0.3 |
| 长发 | 0.4 | 0.6 | 0.2 |

---

### 👋 手臂绑定

#### 步骤

1. **创建手臂变形器**
   - 使用旋转变形器
   - 设置 ParamArmLA/RA

2. **设置动作**
   - 放下: 0
   - 抬起: 1
   - 挥手: 中间值

---

### 👗 裙子绑定

#### 步骤

1. **创建裙子变形器**
   - 使用弯曲变形器
   - 添加物理效果

2. **设置摆动**
   - 创建 ParamSkirt
   - 设置物理参数

## 常见问题解答

### Q1: 为什么我的模型导出后变形不正确？

**A**: 可能的原因和解决方案：
1. 网格密度不足 → 增加网格密度
2. 变形器层级错误 → 检查变形器结构
3. 参数范围设置不当 → 调整参数范围

---

### Q2: 如何让眨眼更自然？

**A**: 
1. 添加中间过渡形状（半闭眼）
2. 使用曲线编辑器调整过渡曲线
3. 设置随机眨眼间隔（3-5秒）

---

### Q3: 头发物理效果不自然怎么办？

**A**: 
1. 调整重力参数（降低重力）
2. 增加阻尼值（减少抖动）
3. 减小弹簧常数（更柔软）

---

### Q4: 如何优化模型性能？

**A**: 
1. 减少网格密度
2. 合并相似的变形器
3. 减少物理计算量
4. 使用适当的分辨率

---

### Q5: 模型在游戏中卡顿怎么办？

**A**: 
1. 检查网格数量
2. 减少物理设置
3. 降低分辨率
4. 优化变形器层级

---

### Q6: 如何创建表情切换？

**A**: 
1. 创建表情参数
2. 设置表情关键形状
3. 在动作文件中调用

---

### Q7: 为什么嘴巴口型不准确？

**A**: 
1. 检查口型参数设置
2. 调整口型形状
3. 使用口型映射文件

---

### Q8: 如何添加眨眼动画？

**A**: 
1. 在参数面板选择眼睛参数
2. 创建眨眼动作文件
3. 设置循环播放

## 最佳实践

### ✅ DO（推荐做法）

1. **命名规范**
   - 使用英文命名
   - 遵循 Live2D 标准
   - 保持一致性

2. **结构清晰**
   - 合理的变形器层级
   - 清晰的参数组织
   - 适当的网格密度

3. **测试充分**
   - 测试所有参数
   - 检查边界情况
   - 验证物理效果

4. **性能优化**
   - 适度的网格密度
   - 必要的物理设置
   - 合理的分辨率

### ❌ DON'T（避免做法）

1. **不要**
   - 使用中文命名
   - 过度复杂的变形器层级
   - 过高的网格密度
   - 不必要的物理设置

2. **避免**
   - 跳过测试步骤
   - 忽略性能问题
   - 使用非标准参数
